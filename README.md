# حفل اختتام الدبلوم التنفيذي لأمن الطيران

عرض تفاعلي عربي يعمل مباشرة من المتصفح، ويتضمن صورًا وفيديوهات وتشغيلًا بملء الشاشة.

## التشغيل المحلي

يمكن فتح `index.html` مباشرة، أو تشغيل خادم محلي من جذر المشروع:

```powershell
python -m http.server 8080
```

ثم فتح `http://localhost:8080`.

## بنية المشروع

- `index.html`: العرض التفاعلي كاملًا.
- `images/`: الصور والأعلام والشعارات المستخدمة فقط.
- فيديوهات الحفل مستضافة ضمن إصدار GitHub `v1.0.0` لتجاوز حدود ملفات النشر الثابت.
- `netlify.toml`: إعداد نشر الموقع الثابت وسياسة التخزين المؤقت للأصول.

## تنبيه مهم قبل الرفع إلى GitHub

ملفات الفيديو الكبيرة محفوظة كأصول إصدار GitHub، بينما يحتوي المستودع الأساسي على ملفات الموقع والصور فقط.
